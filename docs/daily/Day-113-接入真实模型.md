# Day 113 · 接入真实模型（DeepSeek）实测

.env 填好真实 key 后，整条链路切到真模型：

- i-service 启动时自动加载 .env（configured=true，baseUrl=api.deepseek.com/v1）；
- Java 只配 AI_SERVICE_URL=http://127.0.0.1:8008 重启后，/api/ai/chat 返回 mode=langchain。

## 实测结果

| 场景 | 结果 |
|---|---|
| Python /chat「满多少免运费」 | 3.6s，调用 search_knowledge_base，2 条来源，回答含运费/拆单/退货运费 |
| Java /api/ai/chat「怎么申请退款」 | mode=langchain、3 条 sources、conversationId=16，答案含操作路径与退款时效 |
| 前端 SSE（经 5173 代理） | 逐段 delta 正常流出，最终回答完整 |
| 检索评测 | hit@1 14/15、hit@4 15/15 |
| 回答引用评测（真实模型） | 10/10 有引用、**0 条非法引用**，citation_rate=1.0 |

## 已知问题

- **token 统计仍为 0**：LangChain 的流式链路里 stream_usage 的 usage 没有出现在
  esponse_metadata（假模型同样没有）。下一步用 OpenAI callback / 自定义 handler 取 usage，
  或退化为按字数估算；当前先不影响回答。
- 检索对「手机」这类泛词命中率一般（商品名是 iPhone/Xiaomi），模型会自行换词，
  可在工具里做同义词扩展。

## 使用方式

1. i-service/.env 填 OPENAI_API_KEY；
2. 启动 Python：uvicorn main:app --port 8008；
3. 后端环境变量 AI_SERVICE_URL=http://127.0.0.1:8008 启动；
4. 不配这两项时自动回退 mock，不影响主链路与 e2e。
