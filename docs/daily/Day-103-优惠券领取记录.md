# Day 103 · 优惠券领取记录

- 新接口 GET /api/admin/coupons/{id}/records（权限 coupon:list）：
  分页返回该券的 user_coupons 记录，LEFT JOIN users 取昵称（无昵称回退用户名）；
- 券不存在 → 404；分页夹紧沿用 MAX_PAGE_SIZE；
- 管理端优惠券列表新增「领取记录」按钮，弹窗展示用户 ID / 昵称 / 状态 / 领取时间 / 使用时间，带分页。

## 验证

- 新建券 → demo 领取 → records 返回 total=1，userName=演示用户、status=UNUSED；
- 不存在的券 → code=404；
- 前端 lint/build 通过；主链路 e2e 见下一条命令的独立结果。
