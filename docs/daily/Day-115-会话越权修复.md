# Day 115 · AI 会话越权修复（IDOR）

## 问题

/chat 收到 conversation_id 时只按 id 读历史，没有校验归属 —— 猜 id 就能读到别人的对话上下文，
属于典型 IDOR（不安全直接对象引用）。

## 修复

memory.ensure_conversation() 现在：

- 查询条件改为 WHERE id = ? AND user_id = ?，不匹配就**新开会话**；
- 匿名用户（user_id 为空/0）**不复用任何历史会话**，只新建，避免猜 id 拿到上下文；
- 归属判断全部在服务端完成，前端传的 id 只是「想续聊哪个会话」的意图。

## 验证

- user1 首次对话 → conversation 74；
- user2 带 74 提问 → 返回 **75（新会话）**，不是 74；
- user1 再带 74 → 仍然 74（正常续聊）；
- 匿名带 74 → 返回 **76（新会话）**。
