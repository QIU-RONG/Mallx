# Day 69 · 搜索历史 + 浏览历史

- **搜索历史**：聚焦顶栏搜索框时展开「最近搜索」面板（最多 10 条，倒序去重），
  点词直接搜、可一键清空；
- **浏览历史**：看过的商品自动记录（最多 20 件，同一商品只留最近一次），
  个人中心新增「浏览记录」页（缩略图 + 名称 + 价格 + 时间 + 清空）；
- 两者都存在 **localStorage**（mall_search_history / mall_view_history），
  不落库：搜索/浏览是行为不是交易，未登录也要能用，且「清一次就真的没了」。

## 实现要点

- utils/history.ts：所有读取包 try/catch，坏 JSON 按「没有历史」处理；
- 搜索面板用 mousedown.prevent + 120ms 失焦延迟，避免「点历史词先失焦、面板先消失」；
- 浏览记录价格取**第一个 SKU 价**，不是详情接口的 minPrice —— 后者在详情装配里不一定有值。

## 踩坑

改完样式后截图发现下拉是「裸文字」：getComputedStyle(.search-pop) 返回 position: static，
且没有任何样式表含该选择器 —— **vite dev 的 CSS 热更新又没跟上**（模板更新了、样式没更新）。
重启 dev server 后恢复。同 Day 59 的结论：长跑的 dev server 偶尔会漏 CSS，先重启再怀疑代码。
