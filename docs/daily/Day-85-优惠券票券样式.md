# Day 85 · 优惠券改成票券样式

用户原话：**「优惠券的样式能改一下吗」**。

- 「我的优惠券 / 可领取」从 Element 卡片改成**票券**：
  左侧 150px 面额区（¥50 大字 + 满 X 可用）、虚线分割 + 上下齿孔、右侧名称 / 有效期 / 状态；
- 状态改成印章式圆角标签：未使用（橙）/ 已使用（灰）/ 已过期（红）；
  失效券整张降透明度 + 去饱和；
- 可领取的券用同一套票券样式，底部「领取」按钮（hover 变品牌橙）；
- 齿孔是用伪元素画在分割线上的半圆（与页面同色）—— 一开始被 overflow:hidden 裁掉，
  改成外层不裁剪、左侧面额区自带圆角，齿孔才露出来。

验证：lint / build 通过，1440 截图（我的券 + 可领取两张票券、齿孔、印章状态）。
