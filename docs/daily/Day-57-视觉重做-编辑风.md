## 1. 真正的病因不是"配色"

先截图再动手，发现四个硬伤（前三个才是主因）：

1. **商品图全是白框**：种子图指向 `https://oss.mallx.local/...`，域名解析不了；
2. **对比度低**：`#606266` / `#909399` 铺在 `#f5f7fa` 上，副标题与计数发虚；
3. **卡片没有定义**：白卡铺白底，无边框无阴影；
4. **首屏太淡**：浅橙渐变 + 白字。

★ 还有一个**假象**：第一轮截图整页发灰，我差点把它归因成"配色太淡"。
实际是 Vue 路由淡入动画（0.18s）被截在了中间 —— 整页 opacity ≈ 0.5。
**截图工具会截到动画中间态；判断颜色前要让动画停下。**

## 2. 令牌（唯一来源）

```text
纸底 #faf8f4 · 卡片 #fff · 墨 #191714 · 次 #57534c · 弱 #786f64
发丝线 #e7e2d9 · 动作橙 #ff6700 · 深色段 #191714
卡片圆角 10px · 媒体 6px · 按钮 6px · 缓动 cubic-bezier(.2,.6,.2,1) 180ms
```

- **橙色只剩三种用途**：主按钮、选中态、价格旁的"立省"。
- **价格改墨色衬线**（Georgia）：红色留给"降价"；整数/小数拆开保留，一列价格能竖向对齐。
- Element Plus 的语义色整体映射到这套令牌（`--el-text-color-*` / `--el-border-color`），
  所以 el-table / el-input / el-tabs 不用逐个 `:deep` 覆写。

## 3. 改了什么

**全局壳（App.vue）**
- 去掉「浅灰工具条 + 主导航」两层，合并成一条 68px 吸顶栏（纸底 + 1px 底线 + 毛玻璃）；
- 品牌改成衬线字标 `MallX` + 墨色方块（橙色不再用于 logo）；
- 品类选中态：墨色字 + 2px 橙下划线；右侧收进 订单 / 售后 / 券 / 登录 的 12px 文字链接；
- 搜索框改线框，按钮墨色（把橙色留给真正的购买动作）。

**首页（ProductList.vue）**
- hero 换深色整宽段：eyebrow + 40px 标题 + 副题 + 橙色 CTA + 右侧同心圆几何；
- 筛选条去掉卡片感，改成一行下拉 + 发丝线；
- 卡片：1px 线 + 10px 圆角 + 4:5 图区；hover 只加深边框 + 上移 2px（**不再有橙色光晕**）。

**详情页（ProductDetail.vue）**
- 左图右信息，主图 1:1；价格不铺灰底，40px 衬线字直接站出来；
- 规格选中 = 墨底白字（不用橙色浅底）；
- 详情区用发丝线分隔，去掉 el-card。

**登录 / 注册**：去掉 el-card 与橙色块，只留一条居中纵轴（字标 → 说明 → 表单）。

**购物车 / 订单**：表头改 12px 大写弱色；金额衬线 + `tabular-nums`；吸底栏改纸底 + 发丝线。

## 4. 空图兜底（本轮最实的收益）

`ProductThumb.vue`：有图显示图；无图 / 加载失败 / **1.2 秒还没加载完** ⇒ 确定性渐变 + 商品首字。

- 「确定性」：由商品 id 哈希选 4 组暖灰/暖棕渐变，同一商品每次同色（随机色会让人以为图在闪）；
- **超时也算失败**：域名挂起时 `<img>` 既不 load 也不 error，卡片会一直空着；
- 首页 / 详情 / 缩略图 / 购物车 / 订单明细全部走它，仓库里不再有裸 `<img>`。

★ 两个实测坑：
1. 首版 fallback 用 `height:100%`，父级是 `aspect-ratio` 撑高 ⇒ 高度算不出来，首字跑到左上角。改成 `position:absolute; inset:0`。
2. 首页截图里兜底没出现，是截在图片请求挂起期间 —— 于是加了 1.2s 超时兜底。

---

## 5. 可访问性

- 正文 `#191714` on `#faf8f4` ≈ 16:1；次要 `#57534c` ≈ 7:1；弱色调到 `#786f64`（≥4.5:1）；
- `prefers-reduced-motion: reduce` 关闭路由淡入（**不是截图专用开关**：前庭敏感用户同样受益）；
- 卡片 hover 只做颜色 + 2px 位移，不靠动画表达状态。
