# Day 104 · 管理端编辑优惠券

- 新接口 PUT /api/admin/coupons/{id}（权限沿用 coupon:create）：
  - 可改：名称、面额/折扣率、门槛、发行总量、起止时间；
  - **不允许改券类型**（已发出去的券改类型会让历史抵扣无法解释）→ 400；
  - 发行总量不得小于已领取数 → 400；
  - 满减/折扣的两个字段互斥校验与新建一致；
- 前端优惠券列表加「编辑」按钮，复用新建弹窗（标题按模式切换），提交时按 editId 走更新。

## 验证

- 新建（满 150 减 15，20 张）→ 编辑为「满 199 减 25，30 张」→ 200 且列表回读正确；
- 改类型 → 400；把总量改到 0（已领 1）→ 400；
- 前端 lint/build、主链路 e2e 40/40。
