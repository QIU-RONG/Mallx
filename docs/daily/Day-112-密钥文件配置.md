# Day 112 · AI Key 放本地 .env（不进仓库）

- i-service/.env.example（入库模板）→ 复制为 i-service/.env 后填真实 key；
- .env 已加入 .gitignore，不会被提交；
- Python 启动时用 python-dotenv 自动加载 .env（在读取配置之前），
  环境变量优先于文件（load_dotenv 默认不覆盖已有变量）；
- Java 侧放宽：只要配了 AI_SERVICE_URL 就转发给 Python，**不再要求 Java 进程里有 AI_API_KEY**；
  两者都没有时才走 mock。

## 验证

- 在 .env 里填 OPENAI_API_KEY=test-key + 指向本地假模型后，仅启动 Python（不 export 环境变量）：
  /health 返回 configured=true、aseUrl=http://127.0.0.1:8099/v1，/chat 200；
- Java 只设 AI_SERVICE_URL、**不设** AI_API_KEY 启动 8082：/api/ai/chat 返回
  mode=langchain、conversationId=14、4 条 sources —— 说明 key 只在 Python 的 .env 里就够；
- 验证后已把 .env 还原为空白模板；默认 8081 仍 mock。
