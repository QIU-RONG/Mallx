# Day 119 · AI 历史会话列表

- Python：
  - GET /conversations?user_id=：最近 20 个会话（标题=首条用户消息、消息数、更新时间）；
  - GET /conversations/{id}/messages?user_id=：按会话拉消息；**归属不符返回 403**（与 Day 115 同一条边界）；
- Java：
  - GET /api/ai/conversations、GET /api/ai/conversations/{id}/messages 转发到 Python；
  - 游客返回 401 空列表；JsonNode 直接返回会被序列化成节点属性，改用 Map 转换；
- 前端：面板头部「历史」→ 弹窗列出会话，点选后加载消息并恢复 conversationId（可继续对话）。

## 验证

- Java（demo token）：/api/ai/conversations 返回 200、5 条；游客返回 401；
