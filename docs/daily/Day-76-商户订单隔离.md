# Day 76 · 商户后台：订单按店铺隔离

## 做了什么

- 商户 perms 增加 order:list / order:detail，菜单在商户身份下从「商品管理」扩到
  「商品管理 + 订单管理」；
- 管理端订单列表：ShopScope 非空时，SQL 追加
  EXISTS (order_items oi JOIN products p ... WHERE p.shop_id = ?) ——
  商户只看到「至少含一件本店商品」的订单；
- 管理端订单详情：同样用 EXISTS 判定，不含本店商品的订单一律 **404**；
- 平台账号（超管/订单管理员）shopScope = null，行为不变（仍看全站）。

## 验证（实测）

| 项 | 结果 |
|---|---|
| 商户订单列表 | total=1（仅含 Lenovo 的 19 号单） |
| 跨店订单详情 /admin/orders/14 | 404「订单不存在」 |
| 本店订单详情 | 200 |
| 平台 admin 订单列表 | 不受影响（主链路 e2e 40/40） |
| 管理端单测 / lint / build | 48 通过 / 0 警告 / 通过 |

## 已知边界

1. **订单详情仍返回整单明细**：若一张订单同时含多家店的商品，商户能看到别家商品行
   （共享的买家信息/金额也可见）。真正要做「按店拆单」才能彻底解决，属第 3 层；
2. 商户**不能发货/取消**（没有 order:ship / order:cancel），只能查看；
3. 售后仍未按店铺隔离。
