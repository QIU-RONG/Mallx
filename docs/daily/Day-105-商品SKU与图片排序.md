# Day 105 · 商品编辑弹窗支持 SKU 维护与图片排序

- 编辑商品弹窗加载 GET /api/admin/products/{id} 的 skus/images：
  - SKU 行可改规格名、价格、原价；已有 SKU 的编码锁定（编码是库存/订单的对账键）；
  - 可新增 SKU 行（编码可填），未保存的新行可删除；
  - 图片按当前顺序展示缩略图，支持 ↑/↓ 调整主图顺序；
- 保存时按「现有 SKU + 新行」全量下发（后端是差分更新：带 id 的更新、无 id 的新增）；
- 后端 ProductUpdateDTO 早已支持 skus/images，本次只补前端编辑入口。

## 验证

- SKU：商品 1 的首个 SKU 价格 9999 → 9998 → 回读 9998 → 还原 9999；
- 图片：两张图顺序反转后回读反转，再还原；
- 前端 lint / build 通过；主链路 e2e 40/40。
