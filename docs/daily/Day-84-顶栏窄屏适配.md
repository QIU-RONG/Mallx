# Day 84 · 顶栏窄屏适配（品类不再被截断）

用户截图：窗口缩到约 873px 时，顶栏品类最后一个「家用电器」被截成半个字。

## 根因

品类栏一直是 overflow-x: auto（可横向滚动），但**没有任何可见提示**，
用户看到的只是「半个字」；而原来的「收起品类」断点在 760px，873px 落在「仍然显示」区间。

## 改法

- 中等宽度断点从 1199px 提到 **1319px**（1200/1280 窗口用紧凑字号与窄搜索框，
  实测 1200px 下 8 个品类完整显示）；
- **≤1140px 直接整排收起品类**（首页仍有分类下拉，功能不缺），
  不再让它横向滚动 —— 873px 截图确认干净；
- ≤1080px 的旧「缩小品类字号」规则随之删除（已经不用了）。

## 验证

- 873 / 1080 / 1140 / 1200 / 1280 / 1366 / 1440 七档截图：
  ≤1140 无品类栏；1200/1280/1366 八项完整；无截断、无右侧挤压；
- lint / build 通过。
