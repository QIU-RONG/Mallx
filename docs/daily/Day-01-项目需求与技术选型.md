# 2. 项目介绍

## 2.1 项目名称

**MallX**

## 2.2 项目类型

企业级 B2C 电商系统。

## 2.3 项目目标

开发一个完整的电商系统，包含：

- 用户
- 商品
- 购物车
- 库存
- 订单
- 支付
- 营销
- 评价
- 售后
- 管理后台
- 权限管理

第一版采用：

> **模块化单体架构**

后续再逐步演进到微服务。

# 7. 技术选型

## 7.1 后端

| 技术 | 用途 |
|---|---|
| Java | 开发语言 |
| Spring Boot | 后端核心框架 |
| Spring MVC | Web/API |
| Spring Security | 认证与授权 |
| JWT | 用户身份认证 |
| MyBatis-Plus | ORM/数据库访问 |
| Maven | 项目管理 |

---

## 7.2 数据库

使用：

**PostgreSQL**

不使用 MySQL。

---

## 7.3 商品搜索

不使用 Elasticsearch。

使用 PostgreSQL：

```text
Full-Text Search
      +
pg_trgm
      +
GIN
      +
JSONB
```

目标：

> 使用 PostgreSQL 完成商品搜索。

---

## 7.4 前端

| 技术 | 用途 |
|---|---|
| Vue 3 | 前端框架 |
| Vue Router | 路由 |
| Pinia | 状态管理 |
| Axios | HTTP 请求 |
| Element Plus | UI |
| ECharts | 数据可视化 |

---

## 7.5 文件存储

**阿里云 OSS**

- 商品图片
- 用户头像
- 评价图片

# 11. Day 1 完成标准

> 能够清楚回答：

**MallX 是什么？**

企业级 B2C 电商系统。

**第一版做什么？**

用户、商品、购物车、库存、订单、支付、评价、售后、管理后台。

**使用什么数据库？**

PostgreSQL。

**为什么不用 Elasticsearch？**

使用 PostgreSQL 的全文搜索、pg_trgm、GIN、JSONB 完成搜索。

**采用什么架构？**

前后端分离 + 模块化单体。

**以后怎么扩展？**

Redis → RabbitMQ → Docker → Spring Cloud Alibaba。
