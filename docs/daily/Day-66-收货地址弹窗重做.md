# Day 66 · 收货地址弹窗视觉重做

用户原话：**「样式太简单了」**（截图：新增收货地址弹窗）。

## 改了什么

- 弹窗从 560 → 600，加一行说明「填写一次，下单时一键选用」；
- 表单分三段：**联系人 / 所在地区 / 详细地址**，段标题用 11px 字距小标；
- 输入框改为**浅边框圆角 8px**（去掉 Element 默认灰底阴影），聚焦只变边框色，不发光；
- 详细地址加字数上限 120 + 计数器；
- 「设为默认地址」从裸 checkbox 改成**整行卡片 + 右侧 Switch**（标题 + 说明两行）；
- 底部：取消改文字链（20px 间距）+ 主按钮「保存地址」。

## 验证

- 
pm run lint 0 警告；
pm run build 通过；
- 弹窗截图（1440）检查：分段标题、输入框、默认开关、底部按钮均正常；
- 逻辑零改动（校验/提交/默认地址互斥仍走原有代码）。
