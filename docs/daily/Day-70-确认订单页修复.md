# Day 70 · 确认订单页：地址/优惠券选择改为卡片

用户截图：确认订单页地址是一列**裸 radio + 文字挤在一起**，且同一条地址重复 12 次。

## 根因

1. **样式**：地址用 el-radio 渲染，外面又给 .addr 套了 display:flex。
   Element 的 radio 根节点内部是「圆圈 + label」两段，被外层 flex 重排后，
   圆圈与文字被拉开、整列看起来居中且没有边界 —— 即截图里的样子。
2. **数据**：e2e 每跑一次就 POST /api/addresses 建一条地址，12 次跑下来
   demo 账号有 13 条一模一样的「E2E 测试 / 测试路 1 号」。

## 改法

- 地址选择不再用 el-radio：改成**整块可点的卡片**（自绘圆点 + 姓名/电话/默认徽标 + 地址），
  选中态用深色边框 + 浅底 + 右侧对勾；列表限高 360px 可滚动；
- 优惠券同样改成卡片（不再用 radio），条件文案单独一行；
- 清掉 demo 账号多余的测试地址，只留 2 条。

## 验证

- lint 0 / build 通过；
- 截图：两张地址卡、选中态、默认徽标、优惠券卡与底部合计均正常。
