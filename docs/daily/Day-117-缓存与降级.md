# Day 117 · AI 稳定性与成本（缓存 + 降级）

## 问题缓存

- 政策类问题按 模型 + 问题文本 做进程内缓存（TTL 10 分钟），命中直接返回，不再调模型；
- 只缓存「有依据、未拒答」的政策回答；不含用户数据的问题才缓存（带 userId 的订单类不缓存）；
- 命中时写库（elapsed=0）并返回 cached=true。

实测「优惠券过期还能用吗」：首次 2.81s / 654+49 tokens；再次 **0.39s、cached=true、elapsed=0**，回答一致。

## 模型失败降级

- executor.invoke 抛异常时，若知识库能检索到内容，直接返回「检索原文 + 来源」，
  并标记 allback=true、grounded=true；查不到才继续抛错；
- Java 侧原有的超时/失败兜底文案不变（两层兜底）。

## 限流

- 网关层已有 Java AiRateLimiter（20 次/分/用户）；
- 本轮未在 Python 复制一份：单实例内两处限流会互相打架；多实例时应换成 Redis 统一限流。

## 验证

- 缓存命中延迟与 token 均下降，回答一致；
- 前端/接口结构不变（新增 cached、allback 字段，前端暂未展示）。
