# Day 81 · 店铺主页（C 端）

- 新增公开接口 GET /api/shops/{id}：只回启用店铺，停用/不存在统一 404；
- C 端商品列表支持 shopId 过滤（GET /api/products?shopId=1），不传仍是全站列表；
- 新页面 /shop/:id：店铺名 + 简介 + 商品数 + 该店商品网格（4 列）、分页；
- 商品详情里的店铺胶囊变成可点击入口（cursor:pointer + title「进入店铺」）。

## 验证

- /api/shops/1 → 200「MallX 自营」；/api/shops/999 → 404；
- /api/products?shopId=1 → 2 件（Lenovo / Huawei），全站列表仍是 5 件；
- 店铺主页截图：标题、简介、两件商品与分页正常；
- 主链路 e2e 40/40。

## 边界

1. 店铺主页没有分类筛选/排序（场景是「逛这家店」，不是比价）；
2. 停用店铺的商品仍可能出现在全站列表（Day 64 的取舍未改）；
3. 店铺信息只读，商户改店名仍走管理端（Day 64 的店铺管理）。
