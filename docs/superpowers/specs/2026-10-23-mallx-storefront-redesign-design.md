# MallX C 端商城 · 视觉重做（编辑风）设计稿

日期：2026-10-23 · 范围：`frontend/mall-app`（管理端不动）

## 1. 为什么做

实际渲染出来（Edge 无头截图）有四个硬伤，与"流行的商城"差距不在配色：

1. **商品图全空**：种子图是 `https://oss.mallx.local/...`，域名解析不了 ⇒ 每张卡片是白框；
2. **对比度低**：正文 `#606266`、次要 `#909399` 铺在 `#f5f5f5` 上，副标题与计数发虚；
3. **卡片没有层次**：白卡铺白底，无边框无投影；
4. **首屏 banner 太淡**：浅橙渐变 + 白字。

## 2. 目标 / 非目标

**目标**：一眼"干净、有取舍、像认真做过的店"；文字可读；卡片有定义；空图不显得坏；
全站令牌统一（暖纸底 + 墨色 + 单一橙）。

**非目标**：不动管理端；不加新功能/新页面；不做深色模式；不引 Web 字体（离线可跑）。

**反目标**：靠大图堆视觉（我们没有图）；把所有东西都加阴影/圆角（会回到"玩具感"）；
再引入第二个强调色。

## 3. 约束

- 无外网字体/CDN：只用系统字体（`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`），
  数字/英文用 `Georgia` 衬线做点缀；
- Element Plus 组件沿用，只覆盖其 CSS 变量与壳层；
- `day49-theme-guard.py` 按主色公式校验色阶 —— 主色保持 `#ff6700` 才能过；
- 现有单测（15 条前端）与 build 必须继续绿。

## 4. 方向（已选）

**方案 1「编辑风」的骨架 + 方案 3「科技感」的层级手法**：
暖白纸底、近黑正文、橙色只用于动作；深色整宽段落与白色卡片交替制造节奏；
卡片用 1px 发丝线而不是阴影。

未选：
- **小米式电商**：需要真实商品图撑密度，我们的图全空 ⇒ 会放大"空壳感"；
- **纯 Taphome 冷灰**：与"暖色购买暗示"冲突，且冷灰 + 橙在低对比下会显脏。

## 5. 设计令牌（唯一来源：`styles/theme.css`）

```text
--mx-paper      #faf8f4   页面底色（暖白）
--mx-surface    #ffffff   卡片/输入框
--mx-ink        #191714   主文字
--mx-ink-2      #57534c   次要文字
--mx-ink-3      #8a8378   占位 / 辅助
--mx-line       #e7e2d9   发丝线（1px）
--mx-accent     #ff6700   只用于主按钮 / 选中态 / 链接 hover
--mx-price      #191714   价格用墨色 + 衬线数字（不再是红色，红色留给"降价"）
--mx-deep       #191714   深色段落底
--mx-card-r     10px      卡片圆角
--mx-media-r    6px       图片圆角
--mx-btn-r      6px
--mx-ease       cubic-bezier(.2,.6,.2,1)  180ms
```

字号（1.25 比例）：12 / 13 / 14 / 16 / 20 / 25 / 32 / 40；
标题字重 600、正文 400，只有 hero 用 500 大字距收紧（`letter-spacing: -0.02em`）；
英文/编号标签：12px、`letter-spacing: .08em; text-transform: uppercase`。

间距：4 / 8 / 12 / 16 / 24 / 32 / 48 / 72；容器 1200px；区块间距 56–72px。

## 6. 页面改造

**全局壳（App.vue）**
- 去掉浅灰工具条，把"我的订单/售后/券/登录"收进主导航右侧的 12px 次要链接；
- 主导航：纸底 + 1px 底线，无阴影；logo 用墨色字标（橙色只保留小方块）；搜索框改为 1px 线框 + 墨色按钮；
- 品类选中态：墨色文字 + 橙色 2px 下划线（编辑风），不再用橙色浅底块。

**首页（ProductList.vue）**
- hero 改为**深色整宽段**（`--mx-deep`）：左侧 40px 白字标题 + 一行 14px 灰字副题 + 一个橙色主按钮；
  右侧留 40% 空位给"图形化占位"（CSS 渐变几何），替掉浅橙渐变；
- 筛选条：去卡片边框，改成一行 13px 标签 + 下拉，与网格用 24px 间距；
- 商品卡：白卡 + 1px 线 + 10px 圆角 + 4:5 图区；图区空图时用**确定性渐变 + 商品首字母**；
  名称 14px/600 两行截断，副标题 13px 次要色一行；价格 20px 衬线 + "起"；
  悬停只做边框加深 + 上移 2px，不加橙色光晕。

**详情页（ProductDetail.vue）**：左图右信息，图区同占位规则；价格区加发丝线分隔；
规格选择改为方块按钮（1px 线，选中墨底白字）；CTA 橙色实心、次按钮描边。

**购物车 / 结算 / 订单 / 券 / 售后**：统一卡片与线；金额一律 `font-variant-numeric: tabular-nums`；
表头 12px 大写次要色；危险动作降为文字按钮。

**登录 / 注册**：居中卡片（无橙色块），标题 25px 墨色，按钮橙色实心；
验证码/辅助文案用 `--mx-ink-2`，确保对比度。

## 7. 空图兜底（关键）

新增 `components/ProductThumb.vue`：`props { src, name, seed }`。
`src` 加载失败或为空 ⇒ 渲染确定性渐变（由 seed 取模选 4 组暖灰/暖棕渐变）+ 名称首字（墨色、18px、衬线）。
所有商品图（首页、详情、购物车、订单）统一走它，禁止再出现裸 `<img>`。

## 8. 可访问性

正文对比度 ≥ 4.5:1（`#191714` on `#faf8f4` ≈ 16:1）；次要文字 ≥ 4.5:1；
按钮最小高度 40px；`:focus-visible` 用 2px 橙色描边；不用动画表达状态。

## 9. 怎么验

1. `day49-theme-guard.py`（主色与色阶成套）；
2. `npm run lint` / `npm run test`（15 条）/ `npm run build`；
3. 用 Edge 无头截图对比改前/改后（首页、详情、登录、购物车）；
4. 重启 `day56-local-e2e.py` 40 条，确认只改样式、业务零回归；
5. 人工点一遍：登录 → 加购 → 结算 → 下单。

## 10. 留给实现者决定

- 渐变兜底的 4 组具体色值；
- hero 右侧几何图形的做法（CSS 渐变环 / 网格点阵）；
- 窄屏断点细节（≤980、≤720）。
