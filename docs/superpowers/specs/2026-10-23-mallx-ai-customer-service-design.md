# MallX AI 客服模块 · 设计稿

日期：2026-10-23 · 范围：C 端（含游客），管理端不做

## 1. 要解决什么

一个悬浮客服，既能做**售前导购**（问商品、找货、比价），也能做**售后查询**（订单到哪了、能不能退、退款进度）。
两者都需要「真实数据」—— 商品与订单必须来自商城自己的接口，**不能让模型凭记忆回答**。

## 2. 三条设计判断（决定了整个实现）

### ① 模型不直接读库，只通过【只读工具】取事实

```
用户问题 → 模型决定调哪个工具 → 后端用当前用户身份执行 → 结果回喂模型 → 模型组织语言
```

工具（第一版三个，全部只读）：

| 工具 | 入参 | 出参 | 数据来源 |
|---|---|---|---|
| `search_products` | keyword、可选 categoryId | 前 5 条：id / 名称 / 价格 / 副标题 | `ProductService.searchProducts` |
| `get_my_orders` | 可选 status | 最近 5 条：单号 / 状态 / 实付 / 时间 | `OrderService.listMyOrders`（**userId 来自 token**） |
| `get_my_refunds` | 无 | 最近 5 条：售后单号 / 类型 / 状态 / 金额 | 售后域查询（按 token 用户） |

★ **价格与状态只能来自工具结果**：prompt 明写「没查到就说没查到，不许编」。
★ 工具不接受 `userId` 参数 —— 归属由 token 决定，这是防越权的唯一可靠位置。
★ 第一版**不做写操作**（不下单、不退款、不改地址），只给入口指引。

### ② 没有 key 也能开发：mock 模式

`AI_API_KEY` 为空时进 mock：不调模型，用规则匹配意图 + 直接调工具，返回模板化回答。
与短信验证码同一个思路 —— 存储/流程/接口全真，只有「生成语言」这一步是替身。
**这样 CI 与本地都能测，接上 key 只换一个 Bean。**

### ③ 默认走 OpenAI 兼容协议

配置项：`AI_BASE_URL`（默认 `https://api.deepseek.com/v1`）、`AI_API_KEY`、`AI_MODEL`（默认 `deepseek-chat`）。
换 OpenAI / 通义 / 本地 vLLM 只改环境变量，不改代码。

## 3. 接口

`POST /api/ai/chat`（SSE，`text/event-stream`；`Accept: application/json` 时退化为普通 JSON）

```json
{ "message": "我的订单到哪了", "history": [{"role":"user","content":"..."},{"role":"assistant","content":"..."}] }
```

- 游客可问商品；问订单时回答「请先登录」，**不调订单工具**。
- 返回事件：`delta`（增量文本）、`tool`（调了哪个工具、结果摘要）、`done`。
- 限流：单用户 20 次/分钟（内存计数，够用且无新依赖）。

## 4. 安全与边界

- 订单/售后工具只查 token 用户；`history` 只保留最近 10 轮，拒绝客户端塞 system 角色；
- 超时 20s，模型调用失败返回固定兜底文案（不把上游错误原样吐给用户）；
- 日志：记录 user、工具名、耗时、token 用量；**不记录完整对话原文**（默认只记长度与前 50 字）；
- 红队用例（进验收脚本）：查别人订单、编造优惠、要求直接退款、要求改价、套 system prompt —— 必须拒绝或引导。

## 5. 前端

`AiChat.vue`：右下角圆形按钮 → 抽屉（380px）。流式逐字显示；空态给 3 个快捷问题
（「有什么手机推荐」「我的订单到哪了」「怎么退款」）；错误态给重试；回车发送。

## 6. 分步

1. `mall-ai` 模块骨架 + `/api/ai/chat`（mock 模式）+ 限流；
2. 三个只读工具 + prompt（含防编造/防越权规则）；
3. 真实模型接入（OpenAI 兼容）+ 工具循环（最多 3 轮）；
4. 前端挂件 + 流式渲染；
5. 验收脚本：正常三问 + 红队五问 + mock 模式跑 CI；控制组：删掉归属过滤/删掉「不编价格」规则必须红。

## 7. 待定（需要你拍板）

- 模型供应商与 key：默认按 DeepSeek 兼容协议；**没有 key 就先跑 mock**，之后配 `AI_API_KEY` 即切真模型。
- 是否允许游客聊天：默认允许，但只给商品工具。
