[3] ★ 层级断言：Security 先于 MVC，白名单只管 GET
==========================================================================

             匿名 GET 在白名单内 ⇒ 直通 MVC ⇒ 命中骨架 throw（这就是链路 A 的断言）
      ✅ POST  /api/products/search           [anon] HTTP 401  code=401   期望 http=401 code=None
             ★ 匿名 POST 不在白名单 ⇒ Security 先拒，永远到不了 MVC —— 白名单是【方法粒度】
      ✅ GET   /api/products/search           [demo] HTTP 200  code=500   期望 http=200 code=500
             带 C 端 token 结果相同：白名单与是否带 token 无关
      ✅ POST  /api/products/search           [demo] HTTP 405  code=405   期望 http=405 code=None
