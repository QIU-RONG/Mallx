  size=0      -> 回传 size=1    records=1  total=6   (夹到 1（不夹时 MP 返回空列表）)

  size=99999  -> 回传 size=100  records=6  total=6   (夹到 MAX_PAGE_SIZE=100)
  size=1      -> 回传 size=1    records=1  total=6   (原样)
  size=6      -> 回传 size=6    records=6  total=6   (原样)
  page=0    -> current=1 size=10 records=6

[10] ★★ 可选过滤：eq(condition, 列, 值) 的 condition 必须写对

  (无)                          -> records=6  total=6   types=['ADMIN_ADJUST', 'CANCEL_RELEASE', 'ORDER_LOCK', 'PAY_SOLD'] skus=[3, 5, 6, 7]   (不筛 = 全量)

  &skuId=5                     -> records=1  total=1   types=['CANCEL_RELEASE'] skus=[5]   (CANCEL_RELEASE 那条)
  &skuId=6                     -> records=2  total=2   types=['ADMIN_ADJUST', 'ORDER_LOCK'] skus=[6]   (ADMIN_ADJUST + ORDER_LOCK)
  &skuId=999999                -> records=0  total=0   types=[] skus=[]   (★ 不存在的 SKU → 空列表，不 500)
  &type=PAY_SOLD               -> records=2  total=2   types=['PAY_SOLD'] skus=[3, 7]   (sku=3 与 sku=7 各一条)
  &type=ORDER_LOCK             -> records=2  total=2   types=['ORDER_LOCK'] skus=[3, 6]   ()
  &type=CANCEL_RELEASE         -> records=1  total=1   types=['CANCEL_RELEASE'] skus=[5]   ()
  &type=ADMIN_ADJUST           -> records=1  total=1   types=['ADMIN_ADJUST'] skus=[6]   ()
  &type=NOSUCH                 -> records=0  total=0   types=[] skus=[]   (★ 不存在的 type → 空列表，不 500)
  &skuId=6&type=ORDER_LOCK     -> records=1  total=1   types=['ORDER_LOCK'] skus=[6]   (★ 两个条件【同时】生效（交集）)
  &skuId=5&type=ORDER_LOCK     -> records=0  total=0   types=[] skus=[]   (交集为空)
  &type=%20                    -> records=6  total=6   types=['ADMIN_ADJUST', 'CANCEL_RELEASE', 'ORDER_LOCK', 'PAY_SOLD'] skus=[3, 5, 6, 7]   (★★ 空格串等价【不筛】—— 验 isBlank() 归一化)
